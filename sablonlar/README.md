# Kopyalanabilir çalışma şablonları

Bu dosyaları özel çalışma alanına kopyala. Köşeli ayraçlı alanları kendi bilgilerinle doldur. Eğitim deposuna gerçek hesap veya müşteri verisi ekleme.

| Dosya | Ne zaman? |
|---|---|
| [İş kaydı](is-kaydi.md) | İlk pilotta bütün kaydı tek dosyada tutarken |
| [Görev brifi](gorev-brifi.md) | Başlamadan önce |
| [Kaynak envanteri](kaynak-envanteri.md) | Mevcut durumu okurken |
| [Karar kaydı](karar-kaydi.md) | İnsan kararı ve AI önerisini ayırırken |
| [Devir](devir.md) | Başka ajana, araca veya kişiye iş verirken |
| [Yardımcı görev kartı](yardimci-gorev-karti.md) | Bir üretim aracına işi verip sonucunu aynı kayda döndürürken |
| [Ana profil](ana-profil.md) | Aynı kimlikten farklı anlatımlar üretirken |
| [Platform kartı](platform-karti.md) | Hesap ve erişim durumunu tutarken |
| [İçerik kartı](icerik-karti.md) | Kaynaktan kanala içerik taşırken |
| [Kabul kaydı](kabul-kaydi.md) | Sonucu kontrol ederken |
| [Kapanış](kapanis.md) | Sonraki oturuma devrederken |

İlk denemede brif, kaynak, kabul ve kapanış bölümlerini [iş kaydı](is-kaydi.md) ile tek dosyada tutabilirsin. Dosya sayısı bir başarı ölçütü değil.
